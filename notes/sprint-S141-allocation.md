## Kernel step

`allocationInstruments` declares read issuer/authority, sending addressee,
receiving command, literal scope words, finite quantity or explicit scoped all,
date eligibility, receipt prerequisites and movement modes. A named scope cannot
substitute generated lots. A cohort carries the call, arm and minimum service its read words actually establish; a service-only cohort does not invent a call link.
Generated lots require their original offer's actual receiving receipt.

The logged dispatch travels normally. Receipt invokes the sending commander's
ordinary compliance and strongest/weakest selection, with stable lot ties.
Command records the undertaking, typed shortfall and selected lot references;
forces partitions mixed containers without changing lot values; movement owns
the join and real routes. Command changes assignment only on receiving possession.
Unmatched lots retain their assignment and place. Selected lots are reserved
against other requests and ordinary mandate commitments. A received unmet request
can be fulfilled by a later logged local choice. Continuing cohort requests need
explicit read words; there is no invented state policy.

An accepted later revision supersedes pending journeys only on receipt; an
unrelated request cannot spend the same reserved lot. An unfinished march leg
is never teleported or reset. Refusals preserve earlier undertakings. Save schema
7 adds optional records and joins; migrations invent no receipt or allocation.
Ownership and FOUNDATION rows name the writers.
