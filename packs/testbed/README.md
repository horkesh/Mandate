# Testbed pack: the Two Rivers

This is a fictional, setting-free two-faction war used to exercise the kernel in M1. It belongs to no real history, so it can be changed freely to provoke mechanisms.

The cast was chosen so the first turns exercise each M1 mechanism:

- `n_organiser`: a famous, cautious grandee holding the strongest army, who distrusts the leader. He objects or refuses (P2, P6).
- `n_appointee`: a political appointee, uncandid and far away by courier. He says yes and slow-walks (P4, P8).
- `n_fighter`: an aggressive junior with no post, waiting for a command (P7 promises).
- `n_war_office`: an office holding the reserve, for transfers (P1).
- Blocs `n_hawks`, `n_moderates` and `n_machine`, with a midterm mandate test on day 120 (P10).

Run it with `npm run run:testbed`.
